A comprehensive personal finance application designed to streamline budget management and provide deeper insights into financial habits.

Key Features
  AI-Driven Categorization: Automatically classifies imported transactions into appropriate budget categories using intelligent pattern recognition.
  Historical Data Integration: Processes past financial records to establish accurate baselines and track long-term spending trends.
  Visual Dashboards: Generates clear, interactive representations of income, expenses, and asset allocation over time.
  Custom Reporting: Allows users to filter and analyze financial data across specific date ranges for tailored insights.

Tech Stack
  Core: Python
  Data Processing: Pandas, SQL
  Visualization: Matplotlib / Plotly
  Analytics: Scikit-learn (for transaction classification)


Getting Started
Follow these steps to set up the project locally:

1. Clone the repository to your local machine using the terminal.

2. Navigate into the new project directory.

3. Install the required dependencies using pip install -r requirements.txt.

4. Execute the main application script to launch the analyzer.
